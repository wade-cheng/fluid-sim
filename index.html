15-418 Final Project: Fluid Simulation

By Wade Cheng, Liam Walker. Project webpage URL at https://wade-cheng.github.io/fluid-sim.

Summary

We plan on implementing a parallel particle fluid simulation on the CPU.

Challenge

Fluid particles might act on any other fluid particle, which is too many interactions to be efficient.

Starting resources

We will start the code from scratch. Still need to review the literature and find references to work from.

Goals

Plan to achieve

  • A parallel fluid simulation and analysis of why we were able to get the speedup we did. The speedup analysis could look at problem-constrained scaling, or also time-constrained scaling to see how we can push for more particles while maintaining a set framerate.

Extra goals

  • live demo of the particle simulation (route the parallel fluid simulation into some renderer)

Platform choice

CPU architecture lends it more tolerance for complicated, branching code. This can let us find and implement interesting structures that give ability to parallelize more.

As a less important point, if we have a live demo, it would be easier because neither of us have CUDA-compatible hardware; rendering a scene out of the Gates cluster would be unideal.
